# Regras do Projeto - The Other Song Brasil

Sempre sincronize o arquivo `demo.html` com o código-fonte da aplicação React + Vite.

## Instrução:
- Sempre que você fizer alterações em `client/src/App.jsx` ou em `client/src/index.css`, você DEVE executar o script de sincronização logo em seguida:
  ```bash
  node scripts/sync_demo.js
  ```
- Garanta que as atualizações geradas no `demo.html` sejam adicionadas ao commit juntamente com as modificações do frontend.
